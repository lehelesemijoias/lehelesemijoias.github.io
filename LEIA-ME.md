# Vitrine Le Helê

Site da vitrine virtual da Le Helê Semi Joias.

- `index.html` — vitrine das clientes (o link que você envia).
- `painel.html` — painel de cadastro (com login).
- `config.js` — endereço e chave do Supabase (preencha antes de enviar ao GitHub).
- `setup.sql` — script para rodar uma vez no Supabase (SQL Editor).

O passo a passo completo está no guia "Como colocar a Vitrine Le Helê no ar".
